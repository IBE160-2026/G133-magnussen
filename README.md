# Group G133

Group project for **IBE160 Programming with AI** at Molde University College, autumn 2026 (15 credits).

This repository contains the application and records how the group developed and tested it using AI. AI Study Buddy is designed for Norwegian students. The application interface is in Norwegian, and the project documentation is in English.
