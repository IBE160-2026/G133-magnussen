# AI Study Buddy — design concepts

Four alternative laptop-first visual concepts for the AI Study Buddy MVP. Each SVG presents the same six screens: start/study session, PDF upload, summary, key concepts, flashcards, and quiz. The concepts vary the visual system while keeping source references and verification status visible.

These are concept sketches for review, not an implemented application and not an agreed final direction. All example study content and cited pages are synthetic demo content; they do not claim to come from a real course PDF.

## Concepts

- `01-kildeatlas.svg` — editorial reference style with source checks in the margin.
- `02-studievenn.svg` — warm, calm study workspace with clear action surfaces.
- `03-kildespor.svg` — restrained source-path visual connecting study points to PDF pages.
- `04-studiesignal.svg` — high-contrast editorial system designed for quick scanning.

Each SVG is 1800 × 1260 and uses vector shapes and text.
